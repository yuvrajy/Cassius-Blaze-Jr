# deprecated/

Reference material — original Cassius Blaze Jr static personal site.

This directory holds the standalone HTML/CSS/photos that originally inspired the
"personal site" half of this product. It is **not active code** and must not be
imported from any application module.

## Who should look here

**Sub-agent 4 (personal sites factory)** should consult these files for visual
design direction when building `app/personal/[subdomain]/...`. Treat them as a
mood board / layout reference, not as a template to mechanically port.

Everyone else: ignore.

## Why it lives here

The repo started life as a single static GitHub Pages site (`cassiusblazejr.com`).
We rebooted the project as a multi-tenant Next.js app, but kept the original
HTML so the visual language carries forward.
